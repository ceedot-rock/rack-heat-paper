# Contributing to "Four levers on AI rack heat"

This is a paper repository: `paper.html` is the public paper, `docs/` holds
supporting lab notes, and `README.md` is the front door. There is no build
step and no code — a browser is all you need to review a change.

## Proposing a change

- Fix a factual error: open a **Correction** issue first if the change affects
  a stated number; small prose fixes can go straight to a pull request.
- Add the source for any new claim (arXiv, vendor datasheet, published spec,
  or your own measurement with a described setup).
- Keep the framing honest: this is a planning envelope from published
  techniques, not a measured rack and not a patent claim. Do not write it
  up as more than that.

## Opening a pull request

Use the pull-request template. Keep edits surgical — one correction or one
section per PR — and quote the before/after sentence in the PR body so the
review is cheap.
