# Security Policy

This is a paper repository — there is no running service, API, or dependency
tree here. The security-relevant failure for a paper is quieter: someone
relying on a wrong number, or the project's name being used to imply an
endorsement it never gave.

## Reporting a concern

Please do not open a public issue for security problems.

- Use GitHub's private vulnerability reporting on this repository
  (Security tab → "Report a vulnerability"), or
- Email: corey@slidphilabs.com with the subject line `rack-heat-paper security`

You can expect an acknowledgement within 3 business days. We will keep you
updated while we investigate and credit you in the fix notes unless you
prefer to stay anonymous.

## In scope

- A claim in the paper that could mislead a real deployment decision if
  quoted as measured data
- Impersonation of the project or of Slid Phi Labs to endorse a product
- Misuse of the paper's text or figures presented as a patent claim

## Out of scope

- Disagreement with the paper's interpretation of published techniques
  (open a Correction issue instead)
- Slid Phi Labs services and infrastructure outside this repository
- Social engineering, spam, or denial-of-service against hosted demos
